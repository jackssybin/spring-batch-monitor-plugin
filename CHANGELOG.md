# Changelog

All notable changes to Spring Batch Monitor Plugin will be documented in this file.

## [1.0.0] - 2025-06-22

### Added

- Initial IntelliJ IDEA plugin for monitoring Spring Batch metadata.
- Job execution list and detail views.
- Step execution list and analysis views.
- Data source configuration with connection testing.
- Statistics panel for batch execution metrics.
- Support for MySQL, PostgreSQL, Oracle, SQL Server, H2, and SQLite JDBC drivers.
- Chinese user interface and bilingual documentation.

## [Unreleased]
